# Blinkit Sales Analysis Dashboard

## Project Overview

This Power BI project analyzes Blinkit's grocery sales performance using 8,523 transaction records.

The dashboard provides insights into:

- Total Sales Performance
- Product Category Analysis
- Outlet Performance
- Outlet Size Analysis
- Outlet Location Analysis
- Customer Ratings
- Product Visibility Impact

The objective is to identify high-performing products, outlet types, and sales trends to support business decision-making.


## Tools Used

- Power BI
- Microsoft Excel
- DAX
- Data Visualization
  

## Dataset Information
<https://github.com/PreetheshShetty/Blinkit-Sales-Analysis-powerbi/blob/main/BlinkIT%20Grocery%20Data.xlsx>

Columns:

- Item Fat Content
- Item Identifier
- Item Type
- Outlet Establishment Year
- Outlet Identifier
- Outlet Location Type
- Outlet Size
- Outlet Type
- Item Visibility
- Item Weight
- Sales
- Rating


## Key Insights

- Comparison of sales by outlet type
- Sales contribution by outlet size
- Sales distribution by location tier
- Impact of product visibility on sales
- Customer rating analysis
- Top performing product categories


## Business Objective

To analyze Blinkit's sales operations and identify opportunities to improve revenue, customer satisfaction, and outlet performance.


## Business Questions Answered

1. Which outlet type generates maximum sales?
2. Which product category contributes most revenue?
3. Which outlet location performs best?
4. What is the average customer rating?
5. Does item visibility impact sales?
6. Which products should be prioritized for inventory management?
